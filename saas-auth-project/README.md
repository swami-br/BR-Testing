# SaaS Auth Project

Project workspace for requirements, prototype planning, development, testing, and documentation of a SaaS authentication experience.

## Structure

- `01-requirements/`: Product requirements and acceptance criteria
- `02-prototype/`: Wireframes, design references, and prototype notes
- `03-development-plan/`: Roadmap, tasks, milestones, and technical decisions
- `04-development/`: Browser-based implementation and assets
- `05-testing/`: Test cases, bug tracking, and evidence
- `06-documentation/`: Setup and architecture documentation
